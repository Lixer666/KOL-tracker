# KOL-tracker Mobile

Ця папка призначена для адаптованої версії бота під запуск на телефоні (наприклад, через Termux на Android).

- Сюди можна копіювати та спрощувати основний код.
- Можна створити окремий requirements.txt для мобільної версії.
- Рекомендовано зберігати тут лише мінімально необхідні файли для роботи бота на телефоні.
